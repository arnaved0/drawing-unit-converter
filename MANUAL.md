# Drawing Unit Converter: how to use it

Open the tool at **https://arnaved0.github.io/drawing-unit-converter/**. It runs in your browser: your files are not uploaded. (The only exception: when you press **Translate**, the text in that one box is sent to Google Translate.)

## 1. Open a drawing
Click **Open drawing…**, or drag a file onto the page.

- Works with **PDF, DWG, DXF, PNG and JPEG** files.
- PDFs and pictures are scanned for text first. This takes a few seconds per page.
- For a PDF with several pages, use the **‹ ›** arrows at the bottom of the drawing.

## 2. Pick the units
In the **Units** panel on the right:

- **Original unit**: the unit the drawing uses. It is usually filled in for you.
- **New unit**: what you want, for example inches or millimetres.

The **Settings** button sets the number of decimal places and other number formats.

## 3. Convert
Every dimension found is highlighted in blue and listed under **Dimensions**.

- **Click a dimension** (on the drawing or in the list) to convert it. Click it again to undo.
- **Convert all** converts everything; **Reset all** undoes everything.

Converted values turn green. They are placed neatly for you: when a new value is longer than the old one, it is moved a little or made slightly smaller so it does not run into lines, arrows or other text. (You can turn this off in **Settings**. A value you move or resize yourself is never moved again.)

## 4. Fix anything that was missed
Click **+ Add box**, then drag a box around the value or text. The tool reads what is inside (any language, including Chinese and Japanese) and shows it to you. Correct it if needed, then choose:

- **Convert values**: converts the numbers in the box.
- **Translate**: translates the text. Pick the language, check the translation, then press **Write translation** to put it on the drawing.

To delete a box, click **− Remove box** and then the box, or press **×** in the list.

## 5. Adjust one value (optional)
Press **⌄** on a row in the Dimensions list to change that one value:

- **Converted text**: type exactly what it should say.
- **Text size**, **Rotation** and **Decimal places**.
- **Reset** puts it back.

To move a converted value, hover over it and drag the round handle that appears.

## 6. Download
Use the buttons at the top right:

- **PDF**: the drawing with the new values.
- **PNG / JPEG**: shown when you opened a picture.
- **DXF**: a CAD file (save it as DWG in your CAD program if you need one).

## Shortcuts
| To | Do this |
| --- | --- |
| Undo | Ctrl+Z (Cmd+Z on a Mac) |
| Zoom | Mouse wheel, or the **+ −** buttons |
| Move around | Drag with the right mouse button |
| Stop adding boxes | Esc |

**Always check the converted values against the original drawing before you use them.** Text read by scanning can be misread.
